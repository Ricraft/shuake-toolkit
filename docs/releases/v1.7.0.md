# 统一启动器 v1.7.0

本次更新新增第三个核心「智慧树 ZHS」，并带回一批 Autovisor、日志与权限修复。

## 更新内容

### 新增：智慧树 ZHS 第三核心

- 中控台新增「智慧树 ZHS」核心卡：状态点、登录徽标（未登录 / 登录已过期 / 已登录）、「启动核心」「扫码登录 / 配置」「检查更新」。
- 内置上游 [pjm314159/zhs](https://github.com/pjm314159/zhs) 的「零补丁」副本（版本 0.1.5，上游 git `50bd236`，GPL-3.0-only），许可证与来源记录在 `zhs/LICENSE`、`zhs/NOTICE.md`、`zhs/UPSTREAM.json`、`zhs/UPSTREAM.sha256`。
- 独立解释器环境 `.runtime/venv-zhs`（Python 3.13/3.14），只装 ZHS 依赖，不与启动器 Playwright 环境互相污染；不依赖 Playwright、不打开浏览器、不弹控制台窗口，进程输出进入统一控制台。
- 扫码登录：启动器内嵌 passport 协议，点「获取二维码」约 2 秒出码，同时落盘 `data/zhs/account-1/.zhs/qrcode.png`；支持「取消登录」「刷新登录态」「清除凭证」。
- 真实会话校验：用 cookies 走 CAS 换票 + `getLoginUserInfo`，返回 `ok / expired / unavailable / none / error`；过期时徽标变红并提示「登录已过期，请重新扫码」，不再出现「凭证已失效却显示已登录」。
- 拉取课程：`python -m zhs fetch` 写入 `.zhs/execution.json`（知到 / hike / AI 三类），课程列表展示为「课程名（课程 ID）」，支持多选与全选，勾选结果持久化（保存配置、切页、扫码轮询后不会被重置）。
- 多门课程在同一个 zhs 进程内按勾选顺序逐门串行（`play -c A -c B`），不开并行；日志开头写明「本次课程：共 N 门（按勾选顺序逐门串行）：…」。
- 支持开始刷课（play）、写作业（homework）、考试（默认不自动提交）；考试确认改为页内模态，不再是原生 `confirm`。
- 验证码救援：zhs 因验证码中断时配置页出现红色提示条，提供「打开课程页验证」「只重跑这门课」「知道了」，验证完成后重跑同一 racId 即可继续。
- 自动答题配置（AI / 题库）写入 `.zhs/config.toml`：AI 提供商下拉（OpenAI / SiliconFlow / DeepSeek / 智谱 / 通义 / 星火 / 豆包 / MetaAI / 自定义）、Base URL 预览、获取模型、API Key 显示与连通性测试、最大 Token；第三方题库开关与查询地址；知到倍速、AI 倍速、单课观看上限、进度阈值。

### 新增：ZHS 核心更新与依赖同步

- 中控台 ZHS 卡新增「检查更新」，弹窗展示当前版本、上游 tag、来源、发布时间、更新日志与外链；上游信息取自 GitHub tags，直连 403 时自动走 gh-proxy。
- 安装流程失败整体回滚：下载 tag 归档并记录 SHA-256 → 备份 `zhs/` → 覆盖源码并清理上游已删文件（比较前统一 CRLF→LF）→ 自动重写 `requirements-zhs.txt` → editable 安装 → 四镜像依次装依赖 → 冒烟 `--version` 与 `play/fetch/homework/exam --help` → 写 `.core_versions.json` 并删除备份。
- 运行中不允许安装（按钮置灰并说明原因）；本地版本高于上游时提示「已跳过降级更新」。命令行同样可用：`python scripts/update_zhs.py --check/--dry-run/--source/--force`。

### 改进：Autovisor

- 账号卡新增「登录方式」下拉（账号密码（自动滑块）/ 扫码登录）：`loginMode=qr` 时打开 `passport.zhihuishu.com` 扫码页，复用核心已有手动登录分支，登录完成写回 cookies。
- 每个账号独立 Cookie：只有默认值（空 / `res/cookies.json`）时才改为 `res/cookies_<账号>.json`，用户自定义路径不被覆盖，修复多账号共用 cookies 互相顶掉。
- 人机验证依赖自检：启动前探测 `runtime_deps` 里的 cv2/numpy，缺失自动下载；仍失败只警告并提示手动拖滑块或改用扫码，不再阻止启动。
- 安装失败不再杀进程：`installer.py` 的 `sys.exit(-1)` 改为抛异常并降级为手动验证；非交互 stdin 兜底，避免退出码被污染。

### 修复

- 进度行补课程名（`playing 3D打印技术与应用（262043） [####] 62.5%`），同一视频的进度帧原地刷新为一行；识别 zhs 的 `\r` 进度格式并合并，剥离 ANSI 颜色码。
- 修掉子进程额外弹出可见 cmd 窗口（`CREATE_NO_WINDOW` 与 `DETACHED_PROCESS` 叠加会新建控制台）。
- 本轮有课程因验证码或错误未完成时跳过自动关机，并在日志中说明。
- 修复工作区 Low 完整性标签导致 Playwright `EPERM mkdtemp`、explorer 弹 `0xc0000142`、日志导出报错的问题（`icacls /setintegritylevel Medium`）；日志导出白名单补 `zhs`。
- 修复取消登录后状态变 error、旧凭证未清；修复 ZHS 更新弹窗「安装更新」点了没反应；修复「GitHub 项目主页」提示未知链接。

### 环境与升级

- `bootstrap.py` 新增 ZHS 通道：查找 Python 3.13/3.14 → 建 `.runtime/venv-zhs` → 按 `requirements-zhs.txt` 安装依赖 → editable 安装 `zhs/` → 校验；新增 `--skip-zhs`、`--zhs-venv-dir` 参数，没找到 3.13/3.14 时只警告、不阻塞启动器。
- 数据落在 `data/zhs/account-1/`（`.zhs/config.toml`、`cookies.json`、`execution.json`、`logs/`），删除核心或更新源码不影响这些数据。
- 打开启动器 → 核心设置 → ZHS 新版核心 → 获取二维码 → 扫码登录 → 拉取课程；已有 `data/zhs/`、`cookies.json` 可直接沿用。

## 已知限制

- ZHS 目前单账号串行；同一 IP 多账号并行存在风控风险，暂缓支持。
- 验证码为网易易盾 JS 组件，只能「打开课程页人工验证 + 重跑」，不做自动过验证。
- 考试模式默认不自动提交，且一次只能处理同类型课程。
- ZHS 更新只校验官方 tag 与本地 SHA-256，无发布方签名，失败依赖备份回滚。
- 启动器自更新只覆盖 `统一启动器.py`、`requirements.txt`、`src`、`web`，不包含 `zhs/`、`requirements-zhs.txt`、`bootstrap.py`；ZHS 源码请走「检查更新」或完整包。
