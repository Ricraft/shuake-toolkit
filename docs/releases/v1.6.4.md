# 统一启动器 v1.6.4

## 更新内容

### 学习通课程列表

- 课程卡片新增任务点进度（已完成 / 总数 + 百分比）与课程截止日期；截止日期只在平台确实给出开课与结束时间时显示。
- 课程是否结束改按课程列表页的真实状态判定。原来的 `isretire` 字段与页面对不上：39 门课里有 29 门被标为已归档，其中 26 门其实仍在进行（例如「金工实训」），另有 7 门已结束却标为未归档。
- 同名但不同班级的课程不再被合并。同一账号下两个班级的「大学物理A2」会分别列出，课程数量从 38 门恢复为 39 门。
- 修正课程名中的不间断空格（U+00A0）与首尾空格造成的匹配问题。

### 课程选择

- 勾选结果直接就是「包含课程」列表，不再与旧内容合并，避免界面显示已添加、实际仍在刷旧课程。
- 点击复选框即可勾选，无需精确点在卡片空白处。
- 全选 / 取消全选只作用于可选课程；已结束课程统一置底、变暗且不可选。
- 弹窗副标题实时显示「共 N 门课程，已选 M 门（E 门已结束不可选）」。

### 更新与下载

- 启动器更新弹窗内嵌下载进度条：显示阶段（下载 / 解压替换）、已下载 / 总量、速度、剩余时间；安装完成后自动关闭。
- 下载或安装失败时进度条转为失败状态并显示原因，按钮变为「重新检查更新」，无需关窗重开。
- 弹窗整体可滚动，窗口较矮时按钮不会被挤出屏幕。
- 核心包下载改为「并发测速选源 + 失败降级」：对 GitHub 直连与各镜像并发采样，按实测吞吐排序后下载，失败自动换下一个源；下载中途速度低于 300 KB/s 也会自动换源（实测由 197–217 KB/s 提升到 2.6 MB/s，120 MB 包约 45 秒）。
- 首次安装同样受益：PyPI 包、Playwright Chromium、Autovisor 的 numpy/opencv 都改成测速选源（实测 PyPI 由清华 364 KB/s 提升到阿里 6.3 MB/s，Playwright 由官方 336 KB/s 提升到 npmmirror 7.9 MB/s）。
- 「检查更新」不再被 GitHub 匿名 API 限流打断：直连返回 403 时自动改走 API 中转通道，并冷却 10 分钟不再试探直连；发布列表与 latest 并行查询（实测由 7.59 秒失败变为 3.82 秒拿到版本与摘要）。
- 镜像默认开启，安全边界不变：核心包仍需通过 GitHub 清单声明的大小与 SHA-256 校验，镜像只改变传输通道。可通过 `LAUNCHER_ALLOW_GITHUB_PROXIES=0` 关闭核心镜像、`LAUNCHER_PROBE_GITHUB_SOURCES=0` 关闭核心测速；pip 与 Playwright 无需开关。
