# Launcher v1.6.3

## Changes

- Aligned Yatori video and exam mode choices for all ten platforms with the bundled official configuration generator. Renamed the Xuexitong cxNode setting to concurrent task-point count; it appears only for video mode 3.
- Added a launcher-side Yatori maximum runtime preference (minutes). It starts when the Yatori process is running, cancels on early exit, and stops only Yatori at the limit. Default 0 disables the limit; timeout is not course completion and does not trigger completion-based shutdown.
- Preserved Yatori AI, external question-bank API with AI fallback, and Xuexitong built-in AI configuration. Course include and exclude lists can both be saved.
- The studyTime value is passed into Yatori configuration. Its internal timing behavior has not been verified with a real account; the launcher-side limit is independent.
- Hardened release packaging to omit runtime QR images, cookies, nested account settings and other private files.

## Packages

- launcher-v1.6.3.zip: launcher-only self-update asset.
- shuake-toolkit-v1.6.3.zip: first-run package; the third-party Yatori executable is downloaded by the bootstrapper and is not bundled.
