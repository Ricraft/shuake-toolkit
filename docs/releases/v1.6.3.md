# 统一启动器 v1.6.3

## 更新内容

- Yatori 十个平台的视频与考试选项对齐官方配置生成器；学习通 cxNode 改名为同时任务点数量，仅视频模式 3 显示。
- 新增启动器侧 Yatori 最长运行时间，默认 0 关闭。设置 12 后从进程运行起最多 12 分钟，到点只停止 Yatori，不代表课程完成，不触发刷完自动关机。
- 保留 Yatori 自身 AI、外置题库 API 与题库 AI 兜底，以及学习通内置 AI 的配置传递；包含和排除课程列表可以同时保存。
- studyTime 传入 Yatori 配置，但核心内部计时效果未经真实账号验证；启动器最长运行时间与它独立。
- 发布包排除运行二维码、Cookie、账号配置和其他私有数据。

## 发布文件

- launcher-v1.6.3.zip：启动器更新包。
- shuake-toolkit-v1.6.3.zip：首次安装引导包；不含第三方 Yatori 可执行文件，首次使用需联网获取。

完整提交记录：https://github.com/Ricraft/shuake-toolkit/compare/v1.6.2...v1.6.3
