# 统一启动器 v1.7.3

本版统一一键启动目标，完善更新进度与重启结果反馈，并加入核心环境准备状态和重试入口。
同时收录此前尚未发布的桌面入口、旧版升级兼容和洛天依 Agent 设置控制改进。

## 更新内容

### 启动目标与核心环境

- 软件设置新增「一键启动目标」，可选择 Yatori、旧智慧树 Autovisor 和新 ZHS。
  中控台「启动所选核心」、启动后自动运行及洛天依的一键启动使用同一份选择。
  默认保留原有两个核心，ZHS 可勾选加入；未安装、未配置或未登录的目标明确提示跳过。
- 使用已保存的核心配置启动，不再因保存其他配置页中的无关草稿阻断一键启动。
  仅启动新 ZHS 时不强制启动本地题库。
- ZHS 卡片显示环境缺失、准备中、失败详情与已就绪，并提供准备/重试按钮。
  准备成功后仍需点击启动核心；准备操作不会自动开始学习任务。
  安装命令成功后继续检查环境导入，校验失败或异常都会保留错误信息。
- 旧智慧树依赖安装失败后保留原因，提供「重试启动」入口；依赖就绪后沿用原有任务启动流程。

### 更新提示、进度与结果

- 启动时后台检查 Yatori、ZHS 和统一启动器版本；核心有更新时显示 New 标记。
  启动器有更新时自动展示一次详情，用户确认后安装。
- 启动器下载、校验与暂存进度保留在更新详情页，失败后可重新检查并重试。
  详情页的「准备完成」表示更新包就绪，最终文件替换由退出后的脚本执行。
- 应用脚本保存更新日志与持久回执；重启后中控台展示结果并核对实际版本。
  更新失败、版本不匹配及结果尚未确认分别提示，可打开日志或标记已读。
  ZHS 环境准备失败单独反馈，不把已经成功的启动器文件替换误报为失败。
- 核心运行、启动准备与同核心更新互斥；安装依赖或下载启动器更新期间保护退出流程。
  停止全部与退出清理覆盖 ZHS 和准备中的核心，退出时停止扫码进程并保留已保存凭证。

### 洛天依 Agent

- 支持查询和修改公开启动器偏好、已有核心配置和题库设置；敏感内容隐藏，写操作统一确认，
  保存后刷新界面。操作范围受字段白名单约束，不任意增删账号或修改内部状态。
- 明确指令优先本地识别，复杂请求再调用模型；完善同义名称、否定、歧义澄清和多步骤计划。
  多步骤失败时停止后续操作并报告已完成部分。
- 限制对话历史、人格和工具返回长度，按意图提供工具，复用同一次请求的重复只读查询。
  字符量优化不等同于实际计费 Token 或费用降幅，真实模型准确率未作量化承诺。

### 桌面入口、兼容与界面

- 完整包提供带图标的 `统一启动器.exe`，使用同目录引导创建或检查环境，兼容中文和空格路径。
  仍需完整安装目录和可用 Python，并非包含全部运行环境的单文件程序。
- 构建时将生成的 EXE 设置为标准用户完整性级别，避免继承 Low 标签导致日志与临时文件写入失败。
- 兼容旧更新器只替换四项路径的升级方式，随 `src/` 提供迁移载荷，首次启动补齐遗漏的
  `bootstrap.py`、`requirements-zhs.txt` 和 ZHS 源码，保留账号配置与运行数据。
- 成功应用后清理对应的启动器更新 ZIP，失败时保留；不批量删除其他核心压缩包或备份。
- 关于页使用「安装 ZHS 更新」入口，Yatori / ZHS 使用云朵更新图标；旧 Autovisor 保留本地适配保护。
  窄窗口下核心操作按钮可换行，避免文字被挤压。

### 发布检查与文档

- Windows 发布流程先运行完整 pytest 与 JavaScript 语法检查，通过后构建两类发布资产，
  并保存 JUnit 报告。原生 EXE 在 Windows 编译和验证。
- 同步开发文档、更新指南和功能完整性评估，区分本地验证、隔离目录脚本执行与真实平台验收。
