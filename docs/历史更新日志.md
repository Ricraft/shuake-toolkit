# 旧关于页更新日志存档

> 2026-11-14 从关于页移出。此文保留历史快照，不是运行时数据源。
> 关于页现在联网读取最新 GitHub Release；新版本说明仅在 `docs/releases/<版本>.md` 维护并随发布上传。

## v1.7.3 - 统一启动目标与环境重试

软件设置新增一键启动目标，中控台、自动运行和洛天依共用所选核心；默认保留 Yatori 与旧智慧树，ZHS 可勾选加入，未配置的核心明确提示跳过。ZHS 卡片显示环境缺失、准备中、失败详情及已就绪，并提供准备和重试按钮；准备完成后再点击启动核心。旧智慧树依赖安装失败显示详情与重试启动入口。

## v1.7.3 - 更新进度与重启结果回执

启动时检查 Yatori、ZHS 和启动器版本；核心有更新显示 New，启动器有更新展示详情，确认后安装。启动器下载进度保留在详情页，支持失败重试；应用脚本保存更新结果和日志，重启后核对实际版本，支持打开日志和标记已读。补齐核心启动与更新互斥、安装期间退出保护，以及 ZHS 扫码进程退出清理。

## v1.7.3 - 洛天依 Agent 设置控制与调用优化

洛天依可查询和修改公开启动器偏好、已有核心配置与题库设置，写操作统一确认，敏感内容隐藏，保存后刷新界面。明确指令优先本地识别，复杂指令再调用模型；限制历史和工具结果长度，按意图选择工具并复用只读查询。完善否定、歧义和多步骤指令处理，执行失败时报告已完成部分。

## v1.7.3 - 桌面入口、旧版升级与发布回归

日常启动使用独立的无控制台进程，避免长期保留 CMD 窗口及关闭终端导致软件退出；引导输出与 GUI 输出分离，启动诊断保存在 logs/launcher_startup_*.log。直接运行 .py 和旧入口同样处理，显式调试模式保留终端输出。

完整包新增带图标的统一启动器.exe，引导环境并兼容中文和空格路径；构建时修正入口的完整性标签，避免继承 Low 导致日志写入失败。旧版本升级补齐遗漏的 ZHS 源码、bootstrap 与依赖清单，成功应用后清理对应启动器 ZIP，失败保留。关于页使用 ZHS 更新入口与云朵图标；Windows 发布流程先跑完整回归和 JS 检查，再构建发布资产。

## v1.7.2 - 旧版本自更新兼容与 ZHS 环境自愈

为旧更新器提供四项 fileList 兼容清单，并通过 fullFileList 提供完整清单。原发布版的 ZHS 环境自愈链路仍有缺口，遗漏文件补齐、环境重试与对应 ZIP 清理在 v1.7.3 中完善。

## v1.7.1 - 启动器自更新自动应用与 ZHS 环境准备

新增更新器在下载校验后启动进程外脚本，等待旧进程退出、备份、替换七项白名单并逐文件校验，再准备 ZHS 环境并重启。文件替换或校验失败回滚；ZHS 环境准备失败只告警，保留启动器更新。核心任务运行中推迟到退出时应用；首次从更旧客户端升级仍受旧更新器限制。自更新包不包含完整包中的 Autovisor、Yatori 资产及全部脚本。

## v1.7.0 - 智慧树 ZHS 第三核心

中控台新增「智慧树 ZHS」核心卡：内嵌 passport 扫码登录与真实会话校验，拉取知到 / hike / AI 课程后按勾选顺序逐门串行刷课，支持写作业与考试（默认不自动提交），因验证码中断可在配置页一键只重跑本课；支持检查上游更新、备份回滚与依赖重装，并新增自动答题（AI / 题库）配置。Autovisor 新增扫码登录方式，每账号独立 cookies，人机验证依赖缺失时自动补装、失败降级为手动验证；同时修复后台进度刷屏、误弹 cmd 窗口与失败课程仍触发自动关机等问题。

## v1.6.4 - 课程进度、下载测源与更新体验

学习通课程列表显示任务点进度与课程截止日期，是否结束改按教务页面状态判定并置底不可选；勾选结果直接就是包含课程列表。核心与依赖下载改为并发测速选源，更新弹窗内嵌下载进度并在完成后自动关闭；「检查更新」遇 GitHub 匿名接口限流时自动改走镜像通道。

## v1.6.3 - Yatori 平台设置与运行时间管理

Yatori 平台选项及视频、考试模式按官方生成器规则展示；学习通账号的学习时长仅传入 Yatori 配置，核心内部效果尚未实测；它不是启动器倒计时。软件设置新增 Yatori 最长运行时间（分钟），默认 0 不限制，达到上限仅停止 Yatori；题库 AI 智能答题与本地题库未命中时的 AI 兜底继续保留。

## v1.6.2 - 启动器更新检查备用探测

「检查启动器更新」遇 GitHub API 限流或网络错误时改用官方 Release 页面探测；下载仍须通过清单大小与 SHA256 校验，页面备用探测仅覆盖 latest 正式版，不包含 beta/prerelease

## v1.6.1 - 启动与运行稳定性修复

修复一键引导的 Python 路径解析、权限处理与提前退出问题；消除启动/停止竞态，完善多账号异常清理，并增强版本记录容错

## v1.6.0 - 一键依赖引导

完整运行包新增 启动依赖.cmd / bootstrap.py：首次启动自动创建本地 venv、安装 Python 依赖、Playwright Chromium 与 Autovisor runtime_deps，并通过 Release 资产准备 Yatori；launcher-*.zip 继续只做自更新

## v1.5.0 - 成就「吃水不忘挖井人」

## v1.3.1 - 自更新完整性加固

## v1.3.0 - 统一启动器检查更新
