## 其他边界

后续 Agent 核对补充（2026-11-14）：原实现仅提供 8 个布尔偏好开关，没有完整设置工具，
且启停缺少 ZHS。当前新增脱敏设置查询与待确认的局部修改，覆盖五类公开设置；
ZHS 启停与保存后的前端刷新已接通。账号增删、内部成就改写与 ZHS 课程名匹配仍不支持，
不能把“自然语言控制”解释为不受限制地修改全部内部状态。

- ZHS 多课确实按传入列表在上游 `play_service.run_courses` 中串行执行；单门异常被捕获后继续，不能把进程退出码 0 等同于全部成功，启动器有日志失败标记兜底。
- ZHS 更新只有存在独立 venv 时才重装与冒烟；没有 venv 时同步源码后准备环境，不能承诺每次更新都已完成冒烟。
- ZHS pip 依赖变化没有锁文件级环境快照回滚；本轮修复保证源码、依赖声明与版本记录恢复，账号数据不动。
- 多个前端测试采用源码字符串/模拟后端；它们通过不等于真实平台功能、视觉布局或网络速度已经验证。
- 没有修改真实账号、课程学习状态、系统 ACL 或 GitHub Release。

## Agent 请求成本与识别专项

本轮新增 `src/agent_intent.py` 和 `tests/test_agent_efficiency.py`：

- 明确的核心/题库启停、常用开关、主题和 Yatori 时限可在本地生成确认，无需请求模型。
- 同义名称覆盖 Yatori/学习通、ZHS/新版智慧树、Autovisor/旧版智慧树等；
  否定、选择与排除条件不执行，“智慧树”目标不清时先澄清。
- “怎么启动”只读解释，“可以帮我启动吗”可请求确认；保留“不用做题”的课程语义。
- 本地连续指令和模型多次写调用形成最多 6 步计划；确认后依次执行，失败停止，
  明确报告已完成部分并刷新已保存设置，不再只保留第一个写调用。
- 前后端限制历史长度、人格和消息字符量；工具说明按意图筛选；设置可按路径读取；
  工具结果压缩，重复只读查询在同一次请求内复用。已确认不支持工具的配置缓存 5 分钟。
- 设置请求样例：全量工具说明 3938 字符，按需说明 2219 字符，减少约 43.7%。
  30 条超长历史压力样例的请求体字符数减少约 96%；不能当作真实计费 Token 或费用降幅。
- 已覆盖无 API Key 的确认流程、否定/礼貌询问、歧义目标、多步骤失败、只读缓存、
  上下文预算及前端实际 JS 请求构造；未调用真实模型做准确率统计。
- 最终全量 **1222 passed、1828 subtests passed**；另有两个既有依赖弃用警告。
